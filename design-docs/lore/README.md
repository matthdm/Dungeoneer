# Dungeoneer — Lore Directory

This directory contains the canonical lore and narrative bible for Dungeoneer. It is the source of truth for all narrative content — dialogue, quest design, lore fragments, and character arcs derive from these documents.

---

## Files

| File | Contents |
|---|---|

| `domains.md` | The six collapsed worlds — philosophy, peak, collapse, biome remnant, artifact type |
| `biomes.md` | Environmental descriptions for all biomes — domain floors and deep non-civilization floors |
| `artifacts.md` | Legendary artifact flavor text — 4 items per domain, recognition guide, cross-domain notes |
| `bestiary.md` | Enemy origins by biome — what they were, what they became, why it's tragic |
